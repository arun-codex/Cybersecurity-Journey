## Key concepts for reference

- A host operating system runs directly on a computer.
- A virtual machine runs a guest operating system within a virtualized environment.
- Virtual machines can help isolate training activities from a normal working environment, but their networking and isolation settings still require attention.
- Use only owned or explicitly authorized systems for practical security exercises.
