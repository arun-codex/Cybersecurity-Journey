## Reference notes — introductory networking

These are supplemental review notes, not a transcript of the lesson or a claim of independently assessed knowledge.

A computer network connects devices so they can exchange information and share resources. Network communication depends on agreed rules called protocols.

| Term | Meaning |
| --- | --- |
| Host | A device participating in a network |
| Client | An application or device requesting a service |
| Server | An application or device providing a service |
| LAN | A local area network |
| WAN | A network spanning a wider geographical area |
| Switch | A device that commonly forwards Ethernet frames on a local network |
| Router | A device that forwards IP packets between networks |
| Protocol | A set of rules governing communication |
| IP address | A logical address used for IP communication |
| MAC address | A link-layer address used for local frame delivery on technologies such as Ethernet |

## Example for review

When a computer requests a webpage, networking protocols enable communication between the client and the server. Local links carry traffic to the appropriate next hop, and routers can forward IP packets across interconnected networks.

The next lessons explain this process through the OSI and TCP/IP models.

## SOC relevance

Networking fundamentals help SOC analysts understand device communication, investigate suspicious connections and interpret network security alerts.
